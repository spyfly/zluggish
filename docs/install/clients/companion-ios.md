# Companion (iPhone and iPad)

Zwift Companion for Zluggish is not supported on iPhone or iPad. The web app shows this under **Apps → Zwift
Companion → iPhone and iPad**.

iOS requires apps to be signed by an approved developer. Patching Companion to trust the Zluggish server changes
the app and invalidates its original signature, so Zluggish cannot provide an installable version for iOS.

Use an [Android phone or tablet](companion-android.md) for Companion instead.
